# Configurations

## Hidden Parameters

- Hold **FILTER** (Blinking) for FILTER Envelope
	- Attack
	- Decay
	- Sustain
	- Release
- Hold **ENV** (Blinking) for AMP Envelope
	- Attack
	- Decay
	- Sustain
	- Release

## Presets in UNO Synth Editor

Windows folder with all the existing Presets:
```
Documents \ IK Multimedia \ UNO Synth Editor
```

## INIT a Preset

1. **OSC**
	- 1st row
		- Wave 1 to Sawtooth
		- Tune 1 value to 0
	- 2nd row (hold to blink)
		- Level 1 to 127
		- Level 2 to 0 (Off)
		- Noise to 0 (Off)
1. **FILTER**
	- 1st row
		- Mode as LP
		- Resonance to 0
		- Overdrive to 0
		- Envelope Amount to 0
1. **CUTOFF** to 127
1. **ENV**
	- 2nd row (hold to blink)
		- Amplitude Attack to 0
		- Amplitude Decay to any value
		- Amplitude Sustain to 127
		- Amplitude Release to 0
1. **LFO**
	- Rate to 0
	- Pitch to 0
	- Filter to 0
1. Oscillators' **LFO** Amount to 0 by selecting one of the first 20 Presets
1. **DELAY**
	- Mix to 0
