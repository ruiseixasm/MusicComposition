# Configurations

## Hidden Parameters

- Hold **FILTER** (Blinking) for FILTER Envelope
	- Attack
	- Decay
	- Sustain
	- Release
- Hold **ENV** (Blinking) for AMP Envelope
	- Attack
	- Decay
	- Sustain
	- Release


## INIT a Preset

- OSC: Wave 1 to Sawtooth
- Wave 2 Level to 0
- Noise Level to 0
- FILTER: Cutoff all the way up (127)
- Resonance to 0
- ENV (Amplitude): Attack to 0, Decay to 0, Sustain to 127, Release to a quick decay
- LFO: Rate and amounts to 0
- DELAY: Mix to 0.
