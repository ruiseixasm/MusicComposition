# Configurations

## Enable MIDI ports
To enable MIDI ports follow these steps:
1. Got to **Edit -> Preferences**
1. Under _MIDI -> Devices_ check the wanted input ports

## Associate a MIDI port to an Instrument
To associate a MIDI port to an Instrument already on a Track, find the **Input** dropdown selector on the Track itself and choose **All Inputs > MIDI Omni** to the chosen Port.
